# Local font assets

These WOFF2 files are the Latin subsets emitted by Next.js from the site's
existing `next/font/google` configuration during the verified local production
build on 11 August 2026. They preserve the approved typography while removing
the remote Google Fonts request that had made GitHub builds intermittent.

- Instrument Serif — regular and italic, weight 400
- Instrument Sans — variable, weights 400–700
- IBM Plex Mono — weights 300, 400, 500, 600 and 700

The families are distributed by Google Fonts under the SIL Open Font License.
Source family pages:

- https://fonts.google.com/specimen/Instrument+Serif
- https://fonts.google.com/specimen/Instrument+Sans
- https://fonts.google.com/specimen/IBM+Plex+Mono

The release evidence records SHA-256 checksums for every committed file.
