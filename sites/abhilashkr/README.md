# Abhilash Kalathil Ramesh - Personal Portfolio

A premium, minimalist, and mobile-responsive personal portfolio website for Abhilash Kalathil Ramesh, Executive Director of the Kairali Ayurvedic Group, wellness leader, and angel investor.

Built using **Next.js**, **Tailwind CSS**, **Motion**, and designed using high-end editorial frontend engineering principles.

## Features
*   **Hero / Introduction:** Large display typography with a high-contrast Kerala Ayurvedic retreat visual.
*   **About Me:** Background detailing a legacy of bridging ancient traditions with modern business scaling.
*   **Work Experience:** Professional history as Executive Director at Kairali, Founding Board Member at AYUSHEXCIL, and Angel Investor.
*   **Key Focus Areas:** Bento grid layout mapping out Core Competencies.
*   **Initiatives:** Visual cards for Kairali Healing Village and KAPPL products.
*   **Awards:** Interactive grid displaying international industry honors.
*   **Contact:** Fully functional styled form with LinkedIn profile integration.

## Getting Started

First, install dependencies:
```bash
npm install
```

Second, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
