## 2. What changed

### 2.1 The sitewide consistency layer (new; every unlocked family)
- `public/design/consistency.css` — 66ch prose measure (`p`, `li`, `dd`, `blockquote`; centred standfirsts stay
  centred), gold ◆ marker on every plain list, hairline `hr`, primary CTA links set as body text → the gold
  52px button, 44px tap targets (row links, heading links, breadcrumb links, `summary`; inline links get 12px
  vertical padding — a bigger hit area with no line moving), form controls 52px / 17px, 24px checkboxes with a
  44px label row, visible gold focus ring, hairline tables, phone table stacking, in-page navs un-stuck under
  700px, fixed 560px/520px image columns collapse to one column, campaign-nine's duplicate masthead folded into
  one quiet row under the site header.
- `public/design/consistency.js` — the two things CSS cannot do: a computed-size **type floor** (uppercase /
  tracked labels ≥ 14px, all other text ≥ 15.5px; only ever sizes UP, on the text's own element) and
  **table labelling** (`data-label` per cell so the phone stacks a header table; header-less tables get their own
  scroll box). Runs its own observer on the design root; never touches boot.ts.
- Scope is by construction: `design-view.tsx` emits `data-ahv-consistency="1"` only for families NOT in
  `english-candidate/consistency-locked-families.json`, generated by `tools/build-consistency-lock.mjs` from the
  served views (homepage, the 36 package pages, the 6 finder hubs, the course family, the packages listing —
  46 families). The homepage and package pages therefore cannot be reached by the layer (D-20260921-14).
- Layout: `app/(english)/layout.tsx` loads both files; nothing else in the pipeline changes.
