# Laptop Archive — Index & Catalog

**Source:** external SSD `/Volumes/Extreme SSD` → `Laptop Download files/` + `Older Files - Old Desktop/`
**Scale:** 10,732 real files (excl. macOS `._` siblings), ~138.5 GB, spanning **2007-04-26 → 2026-07-14** (19 years).
**Indexed:** 2026-07-15 IST.

## What's committed here
- **`BUSINESS_ARTIFACTS.csv`** — 363 business documents (strategy, brand, competitor, prompts, price lists, marketing, design, catalogs), filtered to EXCLUDE anything personal/HR/financial. This is the searchable catalog for the website programme.

## What is NOT committed (privacy)
- **`laptop-archive-index.csv`** — the FULL 10,732-file index — is kept LOCAL only (git-ignored). It lists personal/HR/financial filenames (CVs, invoices, statements) that should not live in the repo. Available on the SSD + the local working tree for lookups; ask if you want a specific slice.
