# Research and Evidence Library

**Snapshot date:** 2026-07-19. The OS does not claim to contain every publication ever written. It contains a curated, traceable synthesis of primary standards, large-sample research, selected academic work, tool documentation and practitioner failure reports. Future research is admitted only through the Source Register and change-control process.

## Evidence classes

1. **Primary standards and first-party platform documentation** - highest authority for platform behaviour and technical requirements.
2. **Large-sample independent research** - useful for benchmark context, not a guarantee for a specific site.
3. **Academic evidence** - used when methodology and applicability are understood; preprints are labelled.
4. **Vendor documentation and datasets** - authoritative for the tool, not for Google or the client’s business truth.
5. **Reddit, forums, YouTube and expert opinion** - used to discover failure modes, questions and implementation tactics; never used alone to set a target or assert causality.
